# AI Agent Library

A practical library of reusable AI agent specs, prompts, knowledge-base templates, and deployment guides for Notion AI, GPTs, Claude Projects, n8n agents, and Vercel web apps.

## What this repo is

This is a buildable library of productized AI agents. Each agent spec is designed to be used as:

- a Notion AI Agent
- a Custom GPT
- a Claude Project
- a Gemini Gem
- an n8n AI Agent
- a Vercel web app or embeddable widget
- an internal operating workflow
- a lead magnet or paid implementation product

## Current packs

- `agents/` — 28 productized agent specs
- `templates/` — build checklist, evaluation scorecard, and Notion database schema
- `platforms/vercel-web-apps/` — docs and starter specs for turning agents into deployable Vercel apps

## Philosophy

Not just a directory of AI agents — a forge for turning prompts into products, workflows, widgets, and operator-grade automation systems.

Tiny robot interns are cute. Tiny robot interns with job descriptions, guardrails, and revenue paths are better.
