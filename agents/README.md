# Agents

This folder contains productized AI agent specs. Each file is structured for conversion into Notion AI Agents first, then GPTs, Claude Projects, Gemini Gems, n8n agents, and Vercel web apps.

## Standard sections

- Productized agent
- Buyer
- Pain solved
- Monetization
- Bio/description
- Instructions
- Rules and guardrails
- Conversation starters
- Knowledge base files
- Integrations/connectors
- Output format
