# ChatGPT-Converted Agents

This folder is for Custom GPTs that should become formal AI Agent Library specs.

A Custom GPT belongs here when it has enough strategic value to become a reusable, platform-neutral agent with:

- buyer / user definition
- pain point
- required knowledge files
- guardrails
- outputs
- monetization path
- future platform expansion notes

## Source

Primary source data:

- `../../source-data/my-gpts/my-gpts-normalized.json`
- `../../platforms/chatgpt-gpts/gpt-to-agent-conversion-map.md`

## Conversion workflow

1. Identify high-value GPTs.
2. Rank conversion priority.
3. Create a formal agent spec.
4. Attach relevant knowledge-base files.
5. Add public/private visibility rules.
6. Link the converted agent back to the original GPT inventory.

## Priority levels

- `P0` — build next
- `P1` — high value
- `P2` — useful but later
- `P3` — archive or revisit
