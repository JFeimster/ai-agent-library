# High-Priority ChatGPT-to-Agent Builds

## 1. SiteForge Agent

- **Source GPT:** SiteForge Operator
- **Target user:** founders, affiliates, builders, agencies
- **Problem solved:** turns raw offer/brand ideas into Vercel-ready website structures
- **Required knowledge files:** brand intake template, landing page template, Vercel deployment guide
- **Suggested tools/actions:** GitHub, Vercel, markdown/JSON generation
- **Monetization path:** website factory service, landing-page starter kits, partner microsites
- **Recommended next step:** create a full formal agent spec under this folder
