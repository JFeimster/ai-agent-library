# ChatGPT GPTs Platform Pack

This directory contains resources, templates, and checklists for converting core AI agent specs into Custom GPTs on the ChatGPT platform.

## Contents

- `my-custom-gpts-inventory.md`: Complete markdown table of all custom GPTs.
- `my-custom-gpts-index.csv`: CSV export of the GPT inventory.
- `gpt-to-agent-conversion-map.md`: Guide on mapping Notion specs to Custom GPT fields.
- `custom-gpt-instructions-template.md`: Boilerplate for writing Custom GPT instructions.
- `gpt-knowledge-file-checklist.md`: Best practices for uploading knowledge files.
- `gpt-publishing-standards.md`: Rules for naming, branding, and publishing.
- `gpt-maintenance-checklist.md`: Routine maintenance and testing steps.
