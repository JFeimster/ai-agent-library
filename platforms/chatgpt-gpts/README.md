# ChatGPT GPTs Platform Pack

This folder will contain implementation guidance for turning canonical AI Agent Library specs into ChatGPT Custom GPTs.

## Purpose

Use this platform pack when an agent should become a Custom GPT with instructions, conversation starters, knowledge files, guardrails, and publishing rules.

## Recommended future files

```text
platforms/chatgpt-gpts/
  README.md
  agent-to-gpt-conversion-guide.md
  gpt-instructions-template.md
  gpt-knowledge-file-rules.md
  gpt-publishing-checklist.md
  gpt-maintenance-checklist.md
  gpt-store-positioning-notes.md
```

## What belongs here

- Custom GPT instruction templates.
- GPT conversion checklists.
- Knowledge file packaging rules.
- GPT publishing and maintenance standards.
- ChatGPT-specific limitations and guardrails.

## What does not belong here

- Canonical agent specs.
- Raw My GPTs exports.
- Private user data.
- Provider-sensitive routing logic.
