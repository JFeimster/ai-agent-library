# GPT Knowledge File Checklist

Use this checklist before attaching knowledge files to a Custom GPT.

## Brand files

- [ ] Brand overview
- [ ] Voice and tone guide
- [ ] Offer map
- [ ] Audience profile
- [ ] Public/private language rules

## Product files

- [ ] Product or service summary
- [ ] Product family map
- [ ] Qualification or fit criteria
- [ ] Pricing or packaging rules, if public-safe
- [ ] FAQs

## Intake files

- [ ] Intake questions
- [ ] Required documents
- [ ] Routing or triage rules
- [ ] Disqualifiers or not-a-fit criteria

## Safety files

- [ ] Privacy rules
- [ ] Sensitive-data handling rules
- [ ] Affiliate disclosure rules
- [ ] Public claims rules
- [ ] Internal-only content warnings

## Source-of-truth rules

- [ ] File has a clear owner
- [ ] File has a last-updated date
- [ ] File says whether it is public, partner-facing, or internal-only
- [ ] File avoids stale URLs and unverifiable claims

## Public/private warning

Do not attach internal routing docs, CRM exports, backend-provider files, or private client records to a public GPT.
