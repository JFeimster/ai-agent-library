# GPT Maintenance Checklist

Run this checklist quarterly or whenever a GPT is moved from internal to partner-facing/public.

## Inventory health

- [ ] GPT still exists
- [ ] Access URL works
- [ ] Name still matches library naming standards
- [ ] Description is still accurate
- [ ] Category is still correct
- [ ] Visibility is still correct
- [ ] Related brand is still correct

## Positioning

- [ ] Clear target user
- [ ] Clear painful job solved
- [ ] Clear output promise
- [ ] No vague AI hype
- [ ] No duplicate with a stronger GPT

## Safety

- [ ] No private client data
- [ ] No secrets, keys, tokens, or credentials
- [ ] No backend-provider bypass paths
- [ ] No approval guarantees
- [ ] No legal/tax/credit repair/financial advice claims
- [ ] Internal-only knowledge is not exposed publicly

## Monetization

- [ ] Can become a lead magnet
- [ ] Can support a paid template
- [ ] Can support a productized service
- [ ] Can support partner enablement
- [ ] Can become a Vercel widget or static tool

## Conversion review

- [ ] Convert to formal agent spec
- [ ] Convert to public lead magnet
- [ ] Convert to partner-facing playbook
- [ ] Keep as internal copilot
- [ ] Archive or consolidate
