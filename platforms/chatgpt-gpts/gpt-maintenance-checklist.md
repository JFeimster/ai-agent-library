# GPT Maintenance Checklist

Routine steps to keep Custom GPTs accurate and functional.

## Quarterly Review

- [ ] Check if the core problem the agent solves has changed.
- [ ] Review conversation logs (if available/permitted) for common failure points.
- [ ] Update knowledge files with new SOPs, matrices, or content.
- [ ] Test the exact prompt outputs to ensure the model hasn't drifted in tone.
- [ ] Verify that all Actions (API calls) are still authenticating and returning valid data.
- [ ] Check if new ChatGPT features (like new file search limits) allow for instructions simplification.
