# GPT Publishing Standards

Rules for naming, branding, and releasing Custom GPTs to ensure consistency.

## Standards

1. **Naming:**
   - Must be descriptive and action-oriented.
   - Avoid generic names (e.g., use `Vercel Launch Smith` instead of `Website Builder`).
2. **Descriptions:**
   - Max 2 sentences.
   - Must state the value proposition clearly.
3. **Profile Images:**
   - Must use a clean, professional icon or generated image.
   - Keep styles consistent across related category GPTs.
4. **Publishing State:**
   - Keep as `Only me` during initial testing.
   - Move to `Anyone with a link` for beta testers or portfolio embeds.
   - Move to `Public` only when fully polished and approved for the GPT Store.
5. **Data Privacy:**
   - Never publish a GPT that contains raw API keys in plain text instructions.
   - Ensure "Use data to train models" is toggled OFF if required by client agreements.
