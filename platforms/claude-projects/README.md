# Claude Projects Platform Pack

This folder will contain implementation guidance for turning canonical AI Agent Library specs into Claude Projects.

## Purpose

Use this platform pack when an agent should run as a Claude Project with organized project knowledge, reusable instructions, artifacts, and long-context working patterns.

## Recommended future files

```text
platforms/claude-projects/
  README.md
  agent-to-claude-project-conversion-guide.md
  claude-project-instructions-template.md
  project-knowledge-organization.md
  artifact-workflow-patterns.md
  claude-limitations-and-guardrails.md
```

## What belongs here

- Claude Project setup guides.
- Claude-specific instruction templates.
- Project knowledge organization rules.
- Artifact workflow patterns.
- Long-context usage notes.

## What does not belong here

- Canonical agent specs.
- Raw transcripts or source dumps.
- Private client data.
- Public static site JSON.
