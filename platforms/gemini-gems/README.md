# Gemini Gems Platform Pack

This folder will contain implementation guidance for turning canonical AI Agent Library specs into Gemini Gems and Google ecosystem assistant assets.

## Purpose

Use this platform pack when an agent should run as a Gemini Gem or support Google Workspace-based assistant workflows.

## Recommended future files

```text
platforms/gemini-gems/
  README.md
  agent-to-gemini-gem-conversion-guide.md
  gemini-gem-instructions-template.md
  google-workspace-knowledge-setup.md
  gemini-limitations-and-guardrails.md
```

## What belongs here

- Gemini Gem setup guidance.
- Gemini-specific instruction templates.
- Google Workspace knowledge and context patterns.
- Publishing, maintenance, and handoff notes.
- Platform-specific limitations and guardrails.

## What does not belong here

- Canonical agent specs.
- Raw exports.
- Private client data.
- Public static site JSON.
- Provider-sensitive routing logic.
