# Gemini Gem Build Standard

Every Gem should have one clear job, one clear user, stable outputs, safe knowledge files, and explicit guardrails.

## Required sections

- Platform
- Category
- Purpose
- Primary users
- Core instructions
- Recommended knowledge files
- Inputs
- Outputs
- Guardrails
- Workspace context
- Conversion path

## Safety standard

Do not include secrets, private client data, API keys, credentials, backend-provider bypass paths, funding guarantees, or legal/tax/financial/investment advice.
