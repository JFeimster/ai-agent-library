# Notion AI Platform Pack

This folder will contain implementation guidance for turning canonical AI Agent Library specs into Notion AI assistants, workspace systems, databases, templates, and operating docs.

## Purpose

Use this platform pack when an agent should live inside a Notion workspace or support a Notion-based operating system.

## Recommended future files

```text
platforms/notion-ai/
  README.md
  agent-to-notion-conversion-guide.md
  notion-database-design-patterns.md
  notion-knowledge-base-setup.md
  workspace-operating-system-patterns.md
  notion-ai-instructions-template.md
```

## What belongs here

- Notion AI conversion guidance.
- Notion database schema patterns.
- Workspace setup notes.
- Notion template packaging rules.
- Notion-specific limitations and guardrails.

## What does not belong here

- Canonical agent specs.
- General knowledge-base files.
- Raw exports.
- Private workspace data.
