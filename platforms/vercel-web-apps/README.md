# Vercel Web Apps Platform Pack

## Purpose

Turn the agent library into deployable Vercel web apps, embedded tools, lead magnets, partner portals, intake assistants, calculators, chat assistants, and SaaS-lite products.

## Core pattern

```text
Landing Page -> Input Form -> Next.js API Route -> Agent Prompt -> AI Provider -> Structured Output -> Optional Webhook/CRM Save
```

## Recommended first builds

1. Funding Pipeline Triage Web App
2. Partner Launch Kit Builder Web App
3. Local Referral Partner Scout Web App
4. SOP Goblin Web App
5. Vercel Asset Librarian Web App

## Default stack

- Next.js App Router
- TypeScript
- Vercel
- Vercel AI SDK or AI Gateway
- Serverless API routes
- JSON agent config
- Optional: Tailwind, shadcn/ui, Supabase, Clerk, Stripe, n8n, Notion API, HubSpot API
