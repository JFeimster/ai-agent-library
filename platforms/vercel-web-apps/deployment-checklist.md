# Vercel Deployment Checklist

## Pre-deployment

- [ ] Build locally
- [ ] Confirm no secrets are committed
- [ ] Confirm server routes own AI calls
- [ ] Confirm loading and error states
- [ ] Confirm mobile layout
- [ ] Confirm output is copyable

## Vercel setup

- [ ] Create Vercel project
- [ ] Connect GitHub repo
- [ ] Set environment variables
- [ ] Deploy preview
- [ ] Test preview
- [ ] Promote to production

## Post-deployment

- [ ] Test form
- [ ] Test AI route
- [ ] Test webhook
- [ ] Add analytics
- [ ] Add domain/subdomain
- [ ] Add noindex if internal/private
