# SOP Goblin Web App

## Agent source

`agents/07-sop-goblin.md`

## User promise

Paste messy notes, screenshots text, chat summaries, or workflow descriptions. Get a clean SOP with steps, owner, QA checklist, and troubleshooting.

## Inputs

Workflow name, messy notes, tools, output format, owner, failure points.

## Outputs

Objective, Prerequisites, Workflow Steps, QA Checklist, Troubleshooting, Owner, Version Notes.

## Integrations

Notion, GitHub docs, Google Drive, n8n, Loom notes.
