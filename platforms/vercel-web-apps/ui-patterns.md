# UI Patterns for Vercel Agent Web Apps

## 1. Tool Landing Page

Sections:

1. Hero
2. Who it is for
3. Pain solved
4. How it works
5. Input form
6. Example output
7. CTA
8. Disclaimer / guardrails

## 2. Agent Form

Recommended fields:

- Name
- Email
- Company
- Role
- Market / niche
- Source notes
- Desired output
- Consent checkbox if collecting lead data

## 3. Result View

Include:

- Agent name
- Timestamp
- Summary
- Structured output sections
- Copy full result
- Copy individual sections
- Download Markdown
- Send/save action
- CTA

## 4. Loading State

Good loading copy:

- "Reading the messy bits..."
- "Turning chaos into a usable plan..."
- "Building your output..."
- "Structuring this into something a human can actually use..."

Avoid fake precision like:
- "Analyzing 48 proprietary factors..."
- "Running bank-level underwriting..."
- "Guaranteeing your future..."

## 5. Error State

Good error copy:

```text
Something broke while generating the result. Your input was not lost. Try again, or copy your notes and run the tool manually.
```

## 6. CTA Patterns

### Funding/finance tools

- Book a funding strategy call
- Start your funding assessment
- Connect with Moonshine Capital
- Get your capital readiness plan

### Partner tools

- Become a partner
- Build your partner launch kit
- Share this with your network
- Request a custom partner page

### Agency tools

- Build this agent for my business
- Get the workflow template
- Request implementation help
