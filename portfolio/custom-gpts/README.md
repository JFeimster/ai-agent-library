# Custom GPT Portfolio

This portfolio organizes Jason Feimster's Custom GPTs as productized assets inside the AI Agent Library.

## Purpose

The Custom GPT portfolio helps turn GPT experiments into:

- public lead magnets
- partner-facing enablement tools
- internal operating copilots
- reusable agent specs
- Vercel tools and widgets
- productized-service delivery assets

- Local Referral / Community
- Experimental / Archive

## Visibility model

- `public` — safe for public directories and lead magnets
- `partner-facing` — useful for approved partners but not ideal for public SEO
- `internal-only` — contains routing, CRM, sensitive workflow, or operational logic
- `archive` — duplicate, stale, unclear, or low-priority

## Conversion paths

A GPT can become:

- a formal agent spec under `agents/chatgpt-converted/`
- a Vercel-powered web tool
- a lead magnet
- a paid template
- an internal copilot
- a partner enablement asset
