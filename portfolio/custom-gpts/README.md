# Custom GPT Portfolio

This directory acts as the public portfolio and categorized inventory for all Custom GPTs.

## Contents

- `custom-gpt-inventory.md`: Complete markdown list of all available GPTs.
- `custom-gpt-index.csv`: CSV export for programmatic usage.
- `funding-finance-gpts.md`: GPTs focused on capital, finance, and funding.
- `affiliate-partner-gpts.md`: GPTs for referral, affiliate, and partner networks.
- `web-vercel-site-gpts.md`: GPTs related to Vercel deployments, UI, and site generation.
- `content-brand-seo-gpts.md`: GPTs for copywriting, branding, and SEO.
- `ops-automation-crm-gpts.md`: GPTs for operations, systems, and HubSpot workflows.
