Browse reusable capabilities, then open any skill in a prefilled builder to generate a usable SKILL.md file and supporting implementation notes.

Skill catalog rule:

Skills are not just cards. A skill should become a reusable capability package with inputs, outputs, workflow, guardrails, examples, and a repo path.

What counts as a useful skill?

A skill is a repeatable capability that an agent, workflow, site, Custom GPT, Notion system, or automation can reuse.

  • It has a narrow job.
  • It defines required inputs.
  • It generates standard outputs.
  • It includes examples and guardrails.
  • It can be reused across more than one asset.
