# Funding Skills

Funding skills help convert traffic and intake answers into readiness signals, route explanations, document requests, and next actions.

## P0 skills

| Skill | File | Primary Use |
|---|---|---|
| Funding Fit Triage Skill | `funding-fit-triage.skill.md` | Route applicants by fit/readiness |
| Fast Disqualifier Detection Skill | `fast-disqualifier-detection.skill.md` | Flag obvious blockers early |
| Required Docs Checklist Skill | `required-docs-checklist.skill.md` | Generate document requirements |
| Funding Readiness Score Skill | `funding-readiness-score.skill.md` | Score readiness and prioritize leads |
| Funding Route Explanation Skill | `funding-route-explanation.skill.md` | Explain recommendations publicly and safely |

## Best app placements

- public funding landing pages
- partner portals
- embedded calculators
- applicant intake flows
- HubSpot / n8n routing workflows

## Guardrails

- No approval guarantees.
- No backend provider exposure in public copy.
- No legal, tax, credit repair, or financial advice.
