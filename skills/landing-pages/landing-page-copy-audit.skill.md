# Landing Page Copy Audit Skill

```yaml
---
name: Landing Page Copy Audit Skill
slug: landing-page-copy-audit
category: landing-pages
audience:
  - builders
  - affiliate partners
  - referral partners
  - marketers
problem_solved: Scores landing page copy for headline clarity, CTA strength, trust, objection handling, and conversion flow.
inputs_required:
  - page URL or copy
  - target audience
  - offer
  - primary CTA
  - traffic source
outputs:
  - conversion score
  - issue list
  - recommended rewrites
  - missing sections
  - CTA improvements
guardrails:
  - Do not add risky funding claims.
  - Do not invent testimonials or proof.
  - Keep compliance disclaimers intact.
recommended_apps:
  - SiteForge tools
  - landing page generators
  - static site QA
integration_notes:
  - Can be used before publishing partner or niche landing pages.
monetization_angle: Improves funnel conversion without requiring a full redesign every time the page smells like 2014 webinar copy.
---
```

## Purpose

Audit landing pages for conversion clarity and safe claims.

## Example prompt

Audit this landing page copy for conversion clarity, CTA strength, objections, trust signals, and risky claims. Return score and prioritized fixes.
