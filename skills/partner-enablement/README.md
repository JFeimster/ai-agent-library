# Partner Enablement Skills

Partner enablement skills help affiliates, funding brokers, and referral partners launch faster, explain the offer better, and take daily action.

## P0 skills

| Skill | File | Primary Use |
|---|---|---|
| Partner Game Plan Skill | `partner-game-plan.skill.md` | Convert income goals into daily actions |
| Commission Estimator Skill | `commission-estimator.skill.md` | Estimate partner commissions and activity targets |
| Partner Profile Builder Skill | `partner-profile-builder.skill.md` | Generate broker/partner profiles |
| Partner Resource Recommender Skill | `partner-resource-recommender.skill.md` | Recommend tools and resources by partner profile |

## Best app placements

- partner portals
- onboarding pages
- commission calculators
- partner directory/profile pages

## Guardrails

- No income guarantees.
- No exaggerated earnings claims.
- No backend provider exposure in public copy.
