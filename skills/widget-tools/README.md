# Widget Tool Skills

Widget tool skills make embedded calculators, Next.js tools, and partner embeds more useful, trackable, and monetizable.

## P0 skills

| Skill | File | Primary Use |
|---|---|---|
| Trucker Repair-to-Revenue Skill | `trucker-repair-to-revenue.skill.md` | Estimate repair recovery and downtime impact |
| Inventory Cash Crunch Skill | `inventory-cash-crunch.skill.md` | Estimate ecommerce inventory funding gaps |
| Contractor Job Float Skill | `contractor-job-float.skill.md` | Estimate working capital needed to float jobs |
| Widget CTA Router Skill | `widget-cta-router.skill.md` | Route widget users to the right CTA |
| Lead Webhook Payload Skill | `lead-webhook-payload.skill.md` | Normalize widget submissions for automations |

## Best app placements

- Vercel widgets
- Wix embeds
- partner iframe embeds
- lead magnet calculators
- CRM webhook flows

## Guardrails

- Label estimates and assumptions.
- No guaranteed funding or outcomes.
- Preserve UTM/referral attribution.
