Tag index

Tags help users cut across the main category structure and discover assets by implementation method, platform, business function, or file type.

How tags should be used

Tags should describe implementation details and cross-category relationships. They should not replace the broader category system.

  • Use tags for platforms like chatgpt, vercel, and notion.
  • Use tags for asset types like schema, prompt-chain, and static-site.
  • Use tags for business workflows like funding, crm, and partner.

Suggested tag discipline

  • Use lowercase slugs.
  • Avoid near-duplicates.
  • Keep platform tags separate from business category tags.
  • Use tags to improve search, not to create taxonomy sprawl.
  • Prefer reusable tags over one-off labels.
