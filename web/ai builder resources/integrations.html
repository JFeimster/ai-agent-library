Integrations

Connector directory for Notion, GitHub, HubSpot, OpenAI, Vercel, Google Drive, n8n, Make, Zapier, Airtable, Stripe, and analytics workflows.

Connector directory purpose:

This page documents practical connector use cases for AI Agent Library builds. It is not an API key vault and should never expose secrets, private tokens, client credentials, or protected workspace data.

Integration design rules

  • Start with a no-auth or read-only implementation whenever possible.
  • Use OAuth only when the user benefit clearly exceeds the setup burden.
  • Use API keys only for server-side integrations; never place secrets in public HTML.
  • Document scopes, failure modes, data boundaries, and human approval checkpoints.
  • Keep connector output structured so it can feed agents, dashboards, static pages, and schemas.
