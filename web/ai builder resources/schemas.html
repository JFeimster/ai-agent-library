Schemas

Schema browser for machine-readable agent, skill, GPT, Vercel, funding product, partner resource, prompt, integration, example, and roadmap models.

Schema layer purpose:

Schemas make the repo machine-readable. They are the bridge between markdown source files, static directories, dashboards, validators, GPT Actions, and future APIs.

Schema usage pattern

  1. Define the entity model in markdown first.
  2. Create a JSON Schema under schemas/.
  3. Add one or more examples under examples/.
  4. Render the schema-backed content into a static HTML page.
  5. Validate future imports before they enter the catalog.

Base schema shell

{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://example.com/schemas/entity.schema.json",
  "title": "Entity",
  "type": "object",
  "required": ["id", "name", "status"],
  "properties": {
    "id": { "type": "string" },
    "name": { "type": "string" },
    "status": { "type": "string" }
  },
  "additionalProperties": false
}
